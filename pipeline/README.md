# JD laptops pipeline (б/у RedmiBook Pro)

Сбор и анализ цен на б/у ноутбуки RedmiBook Pro 14/15 с JD (канал 拍拍严选) + автоматическое обновление.

## Запуск

```bash
./run.sh                 # сбор + отчёт (ежедневный режим)
python3 collect.py collect --max-requests 40
python3 report.py        # отчёт по последнему снимку
```

Отчёт: `../redmibook_pro_auto.xlsx` (рядом, в `jd.com/`).

## Что собирается

1. **Поиск** `so.m.jd.com` по списку запросов из `config.json` → б/у лоты
   (фильтр по «二手 / 成新 / 拍拍 / 爱回收 / 严选»).
2. **Обход соседних SKU** (`family_seeds` ± `family_span`) — так находятся лоты одного
   семейства, которые поиск не показывает.
3. **Паспорта юнитов**: `item.m.jd.com/product/{sku}.html?inspectSkuId={id}` — CPU, GPU,
   RAM/SSD, состояние, износ батареи, царапины, адаптер, номер отчёта.
4. Цена берётся из `selectableList` лота (цена конкретного юнита), не из «цены от».

Снимки: `data/snapshots/snapshot_YYYYMMDD_HHMM.json` (накапливаются, дают динамику).

## Анализ

- **Сводка** — медианы по модели × CPU в ¥ и ₽, Δ к самой массовой версии.
- **Ценовая лестница** — сколько добавляет шаг состояния и поколения.
- **Pro 14 / Pro 15 юниты** — построчно с переводом обозначений JD.
- **Ultra 5 125H / 7 155H** — б/у, если появится, плюс справочные цены новых.
- **Лоты без паспортов** — лоты, где прочитались только цены (диапазон, не цена за CPU).
- **Динамика** — со второго снимка: медианы было/стало.
- **Движение юнитов** — трекинг по № отчёта: появилась позиция (дата, цена), продана/снята
  (последняя цена, сколько дней в продаже), изменение цены. Фильтр — Pro 14/15 и CPU из
  `watch_cpus` (6600H, 6800H, Ultra 5 125H, Ultra 7 155H). Реестр: `data/registry.json`,
  события: `data/events.json`.

## Ограничения и обход

- JD включает антибот (`risk_handler`, ответ 302) после серии запросов. Коллектор
  останавливается, помечает прогон и **не пишет пустой снимок** — прошлые данные целы.
- Пауза между запросами 2.5–4 с (random), кэш страниц 6 ч (`config.json: cache_ttl`).
- Прокси: задайте в `config.json` шаблон вида
  `"https://api.allorigins.win/raw?url={url}"` — коллектор пойдёт через него.
- Лимит запросов на прогон: `max_requests` (по умолчанию 70).

## Курс и модели

- `rate_rub` — курс юаня (сейчас 13).
- `targets` — какие модели попадают в отчёт (`RedmiBook Pro 14`, `RedmiBook Pro 15`).
  Ultra-версии попадают автоматически: они часть тех же моделей.
- `queries` — запросы поиска; добавьте «Ultra» или новые модели.

## Автообновление

- macOS launchd: `launchd/com.jd.laptops.plist` (положить в `~/Library/LaunchAgents`).
- Или вручную: `crontab -e` → `0 10 * * * /path/to/run.sh`.
